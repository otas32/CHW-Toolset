# CHW Toolset

**Free, open-source creative tools for Adobe Photoshop.**

CHW Toolset is an independent Adobe Photoshop UXP extension project focused on practical, artist-friendly tools. Our first module, **Hair Studio**, is being designed to help illustrators and retouchers create natural-looking hair with flexible strand, brush, and color controls.

> **Status: Early development.** There is no installable release yet. Features described below are planned and will be validated against Photoshop's supported UXP APIs.

## Hair Studio — planned features

### Brush and strand controls
- Strand count, scatter, thickness variation, and per-strand opacity variation
- Optional pen-pressure behavior, smoothing, and tapered ends
- Two approaches: Photoshop-native brush integration and custom procedural strand generation
- Support for following a Photoshop path where technically feasible

### Color Options
- Sample colors from the active image with average and variation modes
- Independent saved color palettes
- Controlled lighter/darker and warmer/cooler variations
- Reproducible randomness through a seed-lock option
- Perceptual color variation, with care to avoid unwanted background samples

### Workflow and interface
- Compact, Photoshop-native-feeling UXP panel
- Independent **Brush Presets** and **Color Presets**, including persistent settings
- Clear contextual help for controls and dependencies
- Light and dark theme support consistent with Photoshop

These are design goals, not claims of implemented functionality. Some behavior may require alternatives depending on UXP and Photoshop API limitations.

## Contributing

Artists, designers, testers, and developers are welcome.

- Use **Issues** for bugs, feature requests, and actionable feedback.
- Submit **Pull Requests** for proposed code or documentation changes.
- Share reproducible examples and Photoshop version details when reporting problems.
- Please don't post private contact information, credentials, or sensitive files.
